# HisabAI — Demo Script

## Speak. Track. Collect.

## 1. Introduction

HisabAI is a voice-first digital ledger designed to help small vendors and shopkeepers record transactions, track customer balances, and manage payment reminders.

The core idea is simple:

**Speak → Track → Collect**

Instead of manually maintaining a traditional notebook, a vendor can use natural voice input to prepare a ledger transaction.

HisabAI supports:

* Hindi
* Marathi
* English
* Hinglish

---

# 2. Start the Demo

Open the HisabAI application:

https://hisabai-4p3i.onrender.com/

The home page provides four main sections:

* Home
* Dashboard
* Customers
* Reminders

The interface also supports **Dark / Light mode**.

---

# 3. Home Page

The home page introduces the main workflow:

> **"Good business starts with clear hisab."**

The vendor has two ways to create a transaction:

### Option 1 — Voice

Click:

** Tap to speak**

The vendor can speak the transaction naturally.

Example:

> "Riya ne 200 rupaye ka rice aur tomato liya aur 200 rupaye diye."

HisabAI processes the spoken transaction and prepares the ledger information.

### Option 2 — Manual Entry

If the vendor does not want to use voice, they can select:

**Manual Entry**

This provides an alternative way to add a transaction.

---

# 4. Save the Transaction

After entering the transaction, the vendor can use:

**✓ Save Transaction**

The transaction is added to the digital ledger.

The home page also contains a **Recent Transactions** section showing saved transaction information such as:

* Customer
* Items
* Total
* Paid
* Outstanding

---

# 5. Dashboard

Open:

**Dashboard**

The dashboard provides a quick view of the business.

It displays:

### Today's Sales

The total value of today's transactions.

### Received

The amount collected from customers.

### Outstanding

The amount currently pending as udhaar.

### Customers

The number of customers recorded in the system.

---

# 6. Recent Activity

The dashboard also displays recent business activity.

For example:

**Customer: Riya**

Items:

* Rice
* Tomato

This allows the vendor to quickly review recent transactions.

---

# 7. Customers

Open:

**Customers**

The Customers page allows the vendor to manage their customer list.

The page provides:

**+ Add Customer**

Each customer can have information such as:

* Customer name
* Phone information
* Outstanding balance
* Reminder settings

The available actions include:

**Update | Delete**

This keeps customer records organized in one place.

---

# 8. Payment Reminders

Open:

**Reminders**

The Reminders page is designed for payment collection.

It provides:

> **AI-powered consent-aware voice collection.**

If there are no customers requiring reminders, the system displays:

> "No customers currently need a payment reminder."

For customers with outstanding payments, the vendor can enable reminders and provide the required consent.

The workflow is:

**Outstanding Payment → Customer Consent → Reminder**

# 11. Key Features to Highlight

###  Voice-first interaction

Vendors can speak instead of manually typing every transaction.

###  Indian-language friendly

The interface is designed for Hindi, Marathi, English, and Hinglish.

###  Digital ledger

Transactions are stored digitally with customer, item, payment, and outstanding information.

###  Business dashboard

The vendor can quickly see:

* Sales
* Received payments
* Outstanding udhaar
* Customer count
* Recent activity

###  Customer management

Customers can be added, updated, and deleted.

###  Payment reminder workflow

Customers with outstanding payments can be managed through the reminder system with consent-aware collection.

###  Manual fallback

Transactions can also be entered manually when voice input is not preferred.

# 12. Problem Being Solved

This can make it difficult to keep track of:

* Daily sales

* Outstanding udhaar

HisabAI provides a single digital workflow for these activities.
